# Політика щодо ШІ та LLM

Цей документ викладає політику F5M / I2P щодо використання ШІ та LLM — як для людей, так і для систем, які читають цей репозиторій.

Ми приймаємо внесок за допомогою LLM, адже перевірка патча — це наша робота в будь-якому разі. Людина повинна керувати процесом, розкривати, розуміти й тестувати його, перш ніж хтось інший прочитає.

## Внески, зроблені за допомогою ШІ

Внески, зроблені за допомогою ШІ/LLM, вітаються.

Кожен внесок повинна вести, переглядати та подавати людина — автономні агенти не допускаються.

Ці правила стосуються внесків ззовні проєкту. Супровідники відповідають за власну практику — див. [Як цей проєкт використовує ШІ](#як-цей-проєкт-використовує-ші) нижче.

Учасники повинні повідомляти, коли внесок було зроблено за допомогою ШІ/LLM.

Кожне повідомлення містить:

- назву використаного інструменту (Claude Code, Cursor, Amp …).
- яку частину роботи виконав інструмент.

Додайте цей трейлер до повідомлення коміту:

```text
Assisted-by: <назва моделі або інструменту>
```

Той, хто подає роботу, усе одно зобов’язаний зробити все це:

- **Розумійте зміни.** Якщо ви не можете пояснити зміну та її взаємодію з рештою системи без інструмента — не подавайте її.
- **Спершу перегляньте самі.** Прочитайте кожен рядок, перш ніж просити про це інших.
- **Запустіть код.** Код, написаний для платформи, яку ви не можете перевірити самі, не є перевіреним, хоч би яким правильним він виглядав.
- **Скоротіть текст.** Згенерований текст багатослівний; відредагуйте його. Коментарі про те, що зробила модель, — шум для кожного майбутнього читача.
- **Відповідайте як людина.** На відгук людини відповідає людина — ніколи не автоматика.

| Діяльність внеску | Позиція |
| --- | --- |
| Зображення | Заборонено |
| Відео | Заборонено |

Дозволено: Pull request’и, Повідомлення комітів, Звіти про вади, Обговорення, Рецензування коду, Звіти про безпеку, Код, Коментарі в коді, Документація, Переклади, Проза, Аудіо, Рефакторинг, Виправлення вад, Тести, Граматичні інструменти, Злиття, Випуски, Сортування задач.

## Коли цієї політики не дотримуються

- За перше порушення надається попередження.
- Внесок закривається без розгляду.

## Як цей проєкт використовує ШІ

| Внутрішня діяльність | Хто вирішує |
| --- | --- |
| Pull request’и | Людина, за допомогою ШІ |
| Рецензування коду | Людина, за допомогою ШІ |
| Злиття | Людина, без участі ШІ |
| Випуски | Людина, без участі ШІ |

## Використання вмісту цього проєкту

- `search` — цей вміст може з’являтися в результатах пошуку на основі ШІ.
- `ai-input` — цей вміст може використовуватися як вхідні дані для системи ШІ під час інференсу.

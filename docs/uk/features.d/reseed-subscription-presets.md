# Пресети ресиду й підписок для цензурованих мереж

- Добірний список ресид-серверів у складі образу, тож перший запуск знаходить вузли без опори лише на вбудовані типові значення.
- Добірні підписки адресної книги у складі образу, тож імена eepsite розпізнаються з першого запуску.
- Додаткові сервери й підписки додаються через змінні середовища; кожен вбудований пресет вимикається окремо.
- Наявні дані маршрутизатора ніколи не перезаписуються — зміни з консолі переживають перезапуски.
- Ресид через проксі (HTTP, SOCKS4/5 або внутрішній outproxy I2P) налаштовується змінними середовища для мереж з міжмережевим екраном.
